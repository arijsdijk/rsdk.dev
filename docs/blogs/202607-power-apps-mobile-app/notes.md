## LinkedIn message

Altijd al een standalone native mobile app willen maken die connect met Power Platform data? 

Vorige week kwam in de Power Platform kills repository de power automate plugin beschikbaar. Een super mooie toevoeging waar veel mensen op hebben gewacht, ook ik! Maar toen ik een kijkje ging nemen binenn de plugins viel mijn oog echter op iets heel anders, een andere nieuwe plugin met de naam mobile-apps.

Met deze plugin heb je de mogelijkheid om een native mobile app te bouwen (voor Android of iOS), waarbinnen je kunt connecten met Power Platform data via een Power Apps Native host. De plugin implementeerd een template op basis van Expo, React Native en TypeScript. Microsoft heeft hierbij zelfs een Power Apps Developer App bechikbaar gesteld (nu alleen nog voor iOS), waarmee je je native app op je mobile device (bijvoorbeeld je iPhone kunt testen) kunt testen.
