# Message

Last week, Microsoft dropped the latest Power Platform monthly feature update again, and it is packed with new features. Some are now generally available, while others are still in public preview.

Full Microsoft article: [What’s new in Power Platform: May 2026 feature update](https://www.microsoft.com/en-us/power-platform/blog/2026/05/14/whats-new-in-power-platform-may-2026-feature-update/)

Besides all the AI-related announcements in this update, I was especially happy to see so many Canvas app improvements. It is great to see Microsoft still investing in better modern controls and even adding new controls to Power Apps Canvas apps.

A few Canvas app updates that stood out to me:

- Generally available: Grid container
- Generally available: Power Fx user-defined types (UDTs)
- Modern control updates for Button, Slider, Icon, and Dropdown, with Icon now supporting `OnSelect`

But the one that really stood out to me this time is the new Data Grid control in public preview. It looks clean, feels modern, and is already very functional. Searchable, selectable, and sortable out of the box. Even though it is still in public preview, I think it is already worth some attention.
