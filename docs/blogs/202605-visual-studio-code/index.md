# Visual Studio code

Bij het bouwen van code apps, generative pages of power pages, maken we nu veel wel gebruik van een lokale development server. Vervolgens runnen we de development server en kunnen we via een localhost de resultaten van onze app zien. Maar dan? Dan willen we elementen aanwijzen en onze coding agent vragen om daar aanpassingen op te doen, willen we de console log direct inzien en aan onze coding agent meeveen en willen we direct gebruik maken van de developer tools in onze browser. 

In deze blogpost neem ik jullie mee door de nieuwe integrated browser in VS Code. Ik laat jullie een aantal super handige opties zien binnen deze nieuwe integrated browser.



## New integrated browser

Enige tijd geleden heeft het team van VSCode een vernieuwde geintegeerde browser geiplementeerd. Los van het openenen van url's via deze browser zijn een aantal handige feautures toegevoegd die - zeker in deze tijd waarbij we AI het coderen laten doen - erg goed van pas komen in je dagelijkse werk. 

In deze post laat ik jullie de volgende handigheidjes zien; 

- Add element to chat
- Add console log to chat
- Open developer tools
- Browser settings
- Sharing with agent (insider)


## Open de integrated browser

! Ik vind het zelf nu super fijn om bijvoorbeeld powerapps, dus make.powerapps.com, gewoon in mijn VS-code te gebruiken. 
! Laat zien, leg uit hoe je een webpagina als makeup.powerapps.com kunt toevoegen aan je workspace. 

Ga naar VS code en gebruik de volgende toetsencobinatie ` CMD + P ` op Mac of ` CTRL + P ` op Windows

Hiermee zal het **Quick Access** venster worden geopend. 

Je kunt ook direct klikken op `Open Quick Access`

[Screenshot]

` >Browser: Open integrated browser `

Er zal nu een browser als tabblad worden geopend in je VSCode workspace. Je kunt nu ieder gewenste url ingeven om deze in de browser te laden.

## Local development server

! Bouw een simpele code app als voorbeeld voor deze blogpost. 
! Start de lokale dev server. En laat zien dat als je klikt op localhost, dat de link direct geopend wordt in de integrated browser. 

Als we Code apps, generative pages of Power Pages (BYOC) ontwikkelen, maken we gebruik van een lokale development server. Deze server wordt voor ons gestart als we het commando `npm run dev` ingeven of als onze coding agent dat voor ons doet. 

Na het starten van de server kunnen we de resultaten bekijken via het adres localhost. Standaard staat de integrated browser van VS Code zo ingesteld dat als je klikt op deze link, ga je standaard met de integrated browser openen.
